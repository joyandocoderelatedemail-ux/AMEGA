# Font Awesome Configuration

Detected by the Font Awesome agent tools. Commit this file so the whole team benefits.

## Integration

- **Method:** Self-hosted web fonts from the npm package `@fortawesome/fontawesome-free`, bundled by Vite. `resources/css/app.css` imports `fontawesome.css`, `solid.css`, `regular.css` and `brands.css`. Every layout loads `app.css` through `@vite`, so icons work on every page: the six `resources/views/layouts/*` shells, `components/layout.blade.php`, and `auth/admin-login.blade.php`.
- **Version:** 7.3.1
- **License:** Free
- **Families:** classic (solid, regular), brands

## Defaults

- **Style:** solid
- **Family:** classic

## Import Pattern

There are no JavaScript imports. Icons are plain markup with class names:

- `<i class="fa-solid fa-house" aria-hidden="true"></i>`
- `<i class="fa-regular fa-calendar" aria-hidden="true"></i>` (Free `regular` covers only a subset of icons; check that one exists before using it)
- `<i class="fa-brands fa-facebook" aria-hidden="true"></i>`

## Conventions

- **Lucide coexists.** The site's existing icons are Lucide (`<i data-lucide="..." class="w-4 h-4">`, loaded from unpkg in each layout). Font Awesome sits alongside it; don't convert Lucide icons unless asked.
- **Size and colour:** use Tailwind text utilities on the `<i>`, e.g. `text-sm`, `text-base`, `text-navy-700`. Icons inherit `currentColor`, so they follow the ticketing portal's dark mode without extra rules.
- **Accessibility:** decorative icons get `aria-hidden="true"`. An icon-only button needs an `sr-only` label or `aria-label`.
- **Build:** all Free icons are already in the bundled fonts, so a new icon class doesn't need a rebuild. A new Tailwind class used next to it does: `public/build/` is committed, so run `npm run build` and commit the build. `vite.config.js` makes CSS asset URLs relative (`renderBuiltUrl`) so the fonts load both at the domain root (production) and from the local sub-folder (`/htdocs2/amegatravelandtour/public/`).
- **UI style:** follow the ticketing portal look (see `resources/views/ticketing/airlines/index.blade.php`). Prefer `fa-regular` where Free has the icon, because it matches Lucide's outline style better than `fa-solid`.
